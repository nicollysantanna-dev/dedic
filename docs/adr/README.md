# Registros de decisão arquitetural

Uma ADR registra uma decisão estrutural que seria difícil ou custosa de entender apenas pelo código.

Crie uma ADR quando houver escolha relevante sobre arquitetura, dados, segurança, dependências, estratégia de testes ou operação. Não use ADR para decisões locais e facilmente reversíveis.

## Convenção

- Nome: `NNNN-titulo-curto.md`.
- Status: `proposta`, `aceita`, `substituída` ou `rejeitada`.
- Uma ADR aceita não é editada para esconder mudanças; uma nova ADR a substitui.
- Use `0000-template.md` como ponto de partida.
